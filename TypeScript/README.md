## 🎯 What You'll Be Able to Do by the End

* Set up a TypeScript project from scratch
* Confidently use every core type (primitives, arrays, tuples, unions, literals, enums)
* Model real-world data with interfaces and type aliases
* Write type-safe functions, including overloads and callbacks
* Build object-oriented code with classes, inheritance, and abstract classes
* Write reusable, flexible code using generics
* Use built-in utility types (`Partial`, `Pick`, `Omit`, `Record`, etc.)
* Build a fully-typed Express.js REST API with runtime validation (Zod)

## 🧩 How to Use These Notes

Each class follows the same structure: **Overview → Learning Goals → Explained Concepts with Examples → Full Example → Summary Table → Hands-On Practice**. Go class by class, type out every code example yourself, and complete the practice exercises before moving to the next one.
